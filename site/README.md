# Демонстраційний сайт

Копія навчального проєкту [OnlineShop](https://github.com/bohdanhrushetsjkyjihoro-png/OnlineShop), на якому проводиться аудит доступності.

- `OnlineShop/` — сторінка магазину (Tailwind CSS) і сторінка новин з формою
- `AutoShop/` — сторінка магазину автотоварів (CSS custom properties, темна тема)
- `server/` — Express API для каталогу товарів і форми
